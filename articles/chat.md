# AMR for R Assistant

The AMR for R Assistant answers your questions about the `AMR` package
in a general AI chat service, Claude (by Anthropic) or ChatGPT (by
OpenAI). It instructs the AI to base its answers on the official
documentation on this website, and on the documentation of the exact
package version that you have installed.

## Ask a question

1.  Choose a chat service below. It opens in a new tab, with the
    instructions for the assistant already filled in.
2.  Type your question below the instructions, preferably with your
    package version, which is the output of `packageVersion("AMR")` in
    R.
3.  Send the message.

[Ask Claude](https://claude.ai) [Ask ChatGPT](https://chatgpt.com)

Copy instructions for another AI

## Good to know

- **Check every answer.** An AI can make mistakes, also with these
  instructions. Verify the code and its results before you rely on them.
- **Never enter patient-identifiable data** into a chat service.
- **An account may be needed.** The chat service must be able to read
  web pages for the assistant to work. Whether this requires an account,
  or a paid plan, depends on the service.
- **Claude shows a caution message** for chats that open with filled-in
  text. This is a general safeguard of Claude: read the instructions
  below to see what you send.
- **This replaces the AMR for R GPT.** The assistant used to be a custom
  GPT in ChatGPT, which OpenAI retires on 11 December 2026. The address
  `chat.amr-for-r.org` now leads to this page.
